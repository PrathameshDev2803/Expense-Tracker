# Expense Tracker

> A PHP and MySQL expense management application for recording, organizing and reviewing personal expenses.

## Overview

Expense Tracker is a practical full-stack PHP application built to manage day-to-day expense records.

The project focuses on the fundamentals that power many business applications: forms, CRUD operations, relational database storage, filtering and presenting useful financial information.

## Core Features

- Add and manage expenses
- Expense categorization
- MySQL-backed persistence
- Expense history
- Data editing and deletion
- Structured expense records
- Dashboard-style financial overview
- Responsive web interface

## Getting Started

### Requirements

- PHP 8+
- MySQL / MariaDB
- Apache

### Local Setup

1. Clone the repository.
2. Create a MySQL database.
3. Import the project's SQL/database schema.
4. Configure the database connection.
5. Place the project inside your PHP server directory.
6. Start Apache and MySQL.
7. Open the application locally.
